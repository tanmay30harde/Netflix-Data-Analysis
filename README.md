# Netflix-Data-Analysis
Netflix Data Cleaning & Analysis using Python
URL: https://roadmap.sh/projects/cleaning-netflix-dataset

📌 Project Overview

This project focuses on cleaning, preprocessing, and analyzing the Netflix Movies and TV Shows dataset using Python and Pandas. The objective is to improve data quality, handle missing values, standardize inconsistent data types, and prepare the dataset for further exploratory data analysis (EDA).

The dataset contains information about Netflix movies and TV shows, including titles, directors, cast members, countries, release years, ratings, durations, genres, and descriptions.

🎯 Project Objectives

The project focuses on the following data cleaning operations:

Inspect the dataset using Pandas .info(), .describe(), and .head().

Identify and handle missing values column by column.

Fix mixed data types in the duration column.

Extract numerical duration values and separate duration units.

Convert the date_added column into proper datetime format.

Export the cleaned DataFrame into a new CSV file.
